# GPON: фильтр + карта

Одностраничное веб-приложение для визуализации абонентских подключений GPON на карте с трёхуровневым фильтром по веткам и статусам.

Работает **полностью в браузере** — не требует сервера, установки Python, Node.js или чего-либо ещё. Достаточно открыть HTML-файл.

![скриншот](docs/screenshot.png)

---

## Возможности

- 📂 **Загрузка данных из Excel и CSV** — координаты адресов из `geo_*.xlsx`, список ONU из `vgroups.csv`.
- 🗺️ **Интерактивная карта** (Leaflet + OpenStreetMap) с кластеризацией маркеров.
- 🎨 **Цвет метки зависит от статуса ONU** — активна (зелёный), отключена (серый), заблокирована (красный).
- 🌳 **Трёхуровневый фильтр веток**:
  1. Группа: `slav*` / `bdcom-*` / `— Прочие`
  2. Подгруппа: `bdcom-sla2`, `SLAV_PON`, …
  3. Под-подгруппа: `bdcom-sla2/GPON0`, …
  4. Ветки: `bdcom-sla2/GPON0/1`, `bdcom-sla2/GPON0/12`, …
- 🔎 **Поиск** по адресу, логину, ID, ветке, статусу.
- 💬 **Всплывающая подсказка** при наведении на маркер — не закрывается при уводе мыши.
- 🌓 **Тёмная / светлая тема**, состояние сохраняется.
- 📊 **Статистика** в шапке: веток / ONU / на карте / найдено.
- 🩺 **Диагностика сопоставления адресов** — если часть ONU без координат, покажет примеры несопоставленных адресов.
- ⚡ **Оптимизировано** для больших файлов (тысячи ONU, десятки Excel-файлов).

---

## Быстрый старт

1. Скачайте файл `app.html`.
2. **Дважды кликните** по нему — он откроется в браузере.
3. В шапке нажмите:
   - **📂 Excel с координатами** — выберите один или **несколько** `geo_*.xlsx`.
   - **📂 vgroups.csv** — выберите CSV со списком ONU.
4. После загрузки обоих файлов карта и фильтры построятся автоматически.

> Всё работает офлайн, кроме подложки карты (тайлы подгружаются с `tile.openstreetmap.org`).

## Формат входных данных

### 1. Excel с координатами (`geo_*.xlsx`)

Файл `.xlsx` или `.xls`. **Имя должно начинаться на `geo`** (это подсказка, не блокировка — при желании можно загрузить любое, но появится подтверждение).

На первом листе должна быть таблица с колонками:

| Описание (адрес) | Широта | Долгота |
|---|---|---|
| Россия, край Краснодарский, р-н Славянский, г Славянск-на-Кубани, ул Ленина, дом 5 | 45.2557 | 38.1254 |
| Россия, край Краснодарский, р-н Славянский, х Маевский, ул Мичурина, дом 143 | 45.2781 | 38.0912 |

- **Описание** — полный адрес в том же формате, что и в `vgroups.csv`.
- **Широта** / **Долгота** — числа; поддерживается десятичная запятая (`45,2557`).
- Строка заголовка может быть **не первой** — парсер ищет её в первых 30 строках.
- Можно загрузить **сразу несколько** файлов (Ейск + Славянск + Краснодар и т.д.) — все адреса соберутся в общий индекс.

### 2. Список ONU (`vgroups.csv`)

CSV с разделителем `;`, `,` или табуляцией. Заголовок обязателен.

| ID | Логин | ... | Адрес | ... | Блокировка |
|---|---|---|---|---|---|
| 12345 | SLAV_PON2/3216/0/GPON0/2:1/5 | ... | Россия, край Краснодарский, … | ... | Активна |
| 12346 | bdcom-sla2/3216/0/GPON0/10:1/3 | ... | Россия, край Краснодарский, … | ... | Заблокирована |

Ключевые колонки:

- **`Логин`** — используется для вычисления ветки GPON.
- **`Адрес`** — сопоставляется с колонкой «Описание» из Excel.
- **`ID`** — показывается во всплывающей подсказке.
- **`Блокировка`** — определяет цвет маркера и статус.

Кодировка — UTF-8 или Windows-1251 (определяется автоматически).

## Как формируется ветка

Из логина вида:

```
SLAV_PON2/3216/0/GPON0/2:1/5
```

берётся:

```
SLAV_PON2/GPON0/2
```

Правило: `{сегмент0}/{сегмент3}/{сегмент4}` до знака `:`. Если сегментов меньше 5 — берётся всё до `:`.

Примеры:

| Логин | Ветка |
|---|---|
| `SLAV_PON2/3216/0/GPON0/2:1/5` | `SLAV_PON2/GPON0/2` |
| `bdcom-sla2/3216/0/GPON0/10:1/3` | `bdcom-sla2/GPON0/10` |
| `bruslavceva` | `bruslavceva` |

## Уровни фильтра

| Уровень | Функция | Правило | Пример |
|---|---|---|---|
| **1. Группа** | `getBranchGroup` | начало имени | `slav*`, `bdcom-*`, `— Прочие` |
| **2. Подгруппа** | `getBranchSubgroup` | до первого `/` | `bdcom-sla2` |
| **3. Под-подгруппа** | `getBranchSubsub` | до последнего `/` | `bdcom-sla2/GPON0` |
| **Ветки** | — | полное имя | `bdcom-sla2/GPON0/1` |

Особенности:

- Всё, что начинается с `-` (например `------bdcom-sla5`), попадает в группу **`— Прочие`**.
- Если у ветки только один `/` (например `bruslavceva` или `SLAV_PON/GPON0/5`), 3-го уровня у неё не будет — ветка окажется **напрямую в подгруппе**.
- Галочки на всех уровнях работают: группа → все подгруппы → все ветки; подгруппа → только её ветки.

## Поиск

Поле `🔎 Поиск` в шапке фильтрует одновременно:

- **Дерево фильтра** — остаются только ветки, содержащие строку.
- **Маркеры на карте** — соответствующие ONU подсвечиваются пульсацией, остальные скрываются.
- **Счётчик `🔎`** в шапке показывает число совпадений.

Ищет по всем полям: адрес, логин, ID, ветка, статус.

## Оптимизации

Код рассчитан на работу с большими объёмами (десятки тысяч ONU):

- **`preferCanvas: true`** — отрисовка в canvas вместо SVG.
- **Кластеризация маркеров** через `leaflet.markercluster` с `chunkedLoading`.
- **Кэш иконок** — 3 уникальных `divIcon` на всю карту, а не по одному на маркер.
- **Параллельная загрузка Excel-файлов** через `Promise.all`.
- **`debounce` поиска** — 180 мс, чтобы не перерисовывать дерево на каждый символ.
- **Делегированные обработчики** событий на контейнере фильтра.
- **Быстрый CSV-парсер** на `indexOf` вместо посимвольного цикла.
- **Один проход по данным** при применении фильтров.

На датасете ~8000 ONU и ~170 веток перестройка занимает меньше секунды.

## Диагностика проблем

### «На карте 0 ONU»

Откройте консоль **F12** и проверьте:

```javascript
State.geo.size          // сколько адресов загружено
State.onus.length       // сколько ONU загружено
State.onus.filter(o => o.lat != null).length  // сколько нашло координаты
```

Если 0 совпадений — **адреса в двух файлах не совпадают**. Самая частая причина — **разные регионы**: например, `geo_slav.xlsx` содержит Славянский район, а `vgroups.csv` — Ейский.

Проверить уникальные районы:

```javascript
// в geo
[...new Set([...State.geo.values()].map(v => {
  const m = String(v.address).match(/р-н\s+([^,]+)/i);
  return m ? m[1].trim() : '(без района)';
}))]
```

Если списки районов не пересекаются — нужен Excel именно с координатами того региона, что в vgroups.

### «Файл Excel не читается»

Проверьте, что:
- файл `.xlsx` или `.xls` (не `.csv`);
- на первом листе есть колонка **«Широта»**;
- есть колонки **«Долгота»** и **«Описание»**;
- заголовок не спрятан за многострочной шапкой (>30 строк) — тогда парсер его не найдёт.

### «Попап закрывается сам»

Убедитесь, что в `bindHoverPopup` используется `autoClose: false`, `closeOnClick: false`, `autoPan: false` и **отсутствует** обработчик `mouseout`.

### «Ошибка `Unsafe attempt to load URL file:///...`»

Это не критично. Chrome ругается на открытие HTML напрямую с диска. Если раздражает — запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000/app.html`.
