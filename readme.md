# VOLS — KMZ + GPON Viewer

Локальное приложение для работы с линиями ВОЛС и абонентскими терминалами GPON:
карта, дерево маршрутов KMZ/KML, метки ONU по адресам. Работает офлайн, данные
хранит на диске рядом с `.exe`, в интернет ходит только за тайлами карты.

- Бэкенд: Flask, один файл [`app.py`](app.py)
- Фронтенд: [`templates/index.html`](templates/index.html) + [`static/app.js`](static/app.js), без сборщика
- Библиотеки (Leaflet, markercluster, XLSX) лежат в [`static/`](static) и раздаются локально
- Сборка: PyInstaller onefile → `dist\app.exe`

## Возможности

### Маршруты KMZ

- Загрузка `.kmz` / `.kml` файлами, папкой или перетаскиванием (с вложенностью любой глубины).
- Дерево повторяет структуру папок; **по умолчанию свёрнуто**, раскрытые вручную папки запоминаются на сессию.
- Видимость: чекбокс у маршрута и у папки, поиск по имени/ветке/папке.
- Переименование маршрута и папки, перетаскивание маршрутов и папок.
- **Рисование маршрута отрезками**: кнопка «✏️ Рисовать» — два клика на отрезок, следующий отрезок
  продолжается с конца; можно ответвляться от уже нарисованных вершин.
- **Правка геометрии**: кнопка «📐» — вершины перетаскиваются, клик по вершине выбирает её (или
  соединяет с началом строящегося отрезка), клик по линии вставляет точку в отрезок, правый клик
  удаляет вершину с объединением соседних отрезков. В режимах правки и рисования карта показывает
  все включённые маршруты — поиск и «связка» не скрывают соседние линии.
- **Дорисовка в существующий маршрут**: кнопка «➕» открывает редактор с выбранной концевой вершиной
  и центрирует карту; дальше можно выбрать любую другую вершину или линию.
- **Объединение частей ветки**: отметьте маршруты кнопкой ◻ в строках дерева и нажмите
  «🧩 Объединить» — сервер сшивает отрезки по ближайшим концам в один маршрут; папка сохраняется,
  если все части лежали в одной.
- **Муфты на карте**: кнопка «📍 Муфта» — клик по карте ставит точку-муфту с заданным именем.
  Маркер перетаскивается (координаты сохраняются), переименовывается и удаляется через попап.
  Муфты лежат в `state.json` (поле `closures`) и выгружаются в KMZ отдельной папкой «Муфты».
- **Массовое переименование**: кнопка «🏷 Имена». Если маршруты отмечены ◻ — переименовывает их,
  иначе спрашивает текст для поиска (например, «Измерение круга»). Символ `#` в шаблоне заменяется
  на номер по порядку: «Муфта #» → «Муфта 1», «Муфта 2», … Папки не меняются.
- **Массовый перенос в папку**: кнопка «📁→ В папку» — отмеченные ◻ маршруты или найденные по
  тексту в имени переносятся в указанную папку; папка создаётся автоматически.
- **Привязка (snap)**: новая точка липнет к ближайшей вершине или сегменту (12 px), включается/выключается кнопкой «🧲 Привязка».
- **Отмена**: `Ctrl+Z` — шаг правки, последняя точка при рисовании, а вне режимов — последнее
  сохранение геометрии (история до 20 сохранений).
- Связка с GPON: клик по линии изолирует маршрут и подсвечивает его ветки; связка живёт только
  в памяти и не меняет сохранённые флаги видимости.
- Экспорт: один KMZ со всеми видимыми маршрутами или дерево KMZ-файлов ZIP-архивом. Маршрут-сеть
  выгружается как MultiGeometry (несколько LineString в одном объекте).

### GPON

- Загрузка геобазы из Excel (`geo*.xlsx`, колонки «Широта», «Долгота», «Описание»)
  и списка ONU из `vgroups.csv` (кодировки UTF-8 / CP1251 / KOI8-R определяются автоматически).
- Метки ONU с кластеризацией, цвет по статусу (активна / отключена / заблокирована / другое).
- Фильтры по статусу и по трёхуровневому дереву ветвей, поиск по адресу, логину, ID.
- Правка координат: перетаскивание метки или ввод широты/долготы в попапе, режим «📍 указать на карте»
  для ONU без координат, список «Без координат».
- `gpon_state.json` хранит только необходимые поля: координаты в `geo`, а `lat/lng/_statusKey`
  у ONU вычисляются на клиенте (файл ~4 МБ вместо ~6).

## Запуск

### Готовый `.exe` (рекомендуется)

1. `data\` и `uploads\` живут **рядом с `app.exe`**. Чтобы использовать существующую базу, держите
   `app.exe` в корне проекта (рядом с `data\`) или скопируйте `data\` в папку с exe.
2. Запустите `app.exe` — или [`run-exe.bat`](run-exe.bat): он поднимает сервер, открывает браузер
   и не закрывает окно с логом при ошибке.
3. Браузер: <http://127.0.0.1:5000>. Остановка — `Ctrl+C` в консоли.

Особенности сборки: `runtime_tmpdir='.'` — onefile распаковывается рядом с exe, а не в `%TEMP%`
(на некоторых машинах политика безопасности блокирует распаковку в профильный Temp).
Порт 5000 фиксирован, два экземпляра одновременно не запустятся. Для тайлов карты нужен интернет,
интерфейс и данные работают без сети.

### Из исходников

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py     # или start.bat
```

Отладка включается переменной окружения `VOLS_DEBUG=1` (в сборке всегда выключена).

## Данные и обслуживание

| Путь | Что внутри |
|---|---|
| `data/state.json` | маршруты, папки, флаги видимости, муфты (`closures`) |
| `data/gpon_state.json` | геобаза по адресам и список ONU |
| `uploads/` | копии загруженных KMZ/KML; мусорные файлы удаляются при загрузке |
| `uploads/tree/` | зеркало дерева при экспорте «Выгрузить дерево» |

Данные не хранятся в git (см. `.gitignore`). Резервная копия — скопировать `data\` или воспользоваться
`/state/export` и `/gpon/state/export`. Импорт состояния делает `.bak` и откатывается при ошибке.
Запись отложенная (0.8 с), при штатном выходе сбрасывается.

## HTTP API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Интерфейс |
| POST | `/upload` | Загрузка файлов (`files[]`, `paths[]`) |
| GET | `/routes` | Все маршруты с точками |
| POST | `/routes` | Создать маршрут (`name`, `folder`, `segments`, `branch`; `points` — устаревший вариант) |
| PATCH | `/route/<id>` | Изменить `name`, `branch`, `folder`, `visible`, `segments` |
| DELETE | `/route/<id>` | Удалить маршрут |
| PATCH | `/routes/bulk` | Массовое изменение (`ids`, `patch`) |
| DELETE | `/routes/bulk` | Массовое удаление (`ids`) |
| POST | `/merge` | Объединить маршруты (`ids`, `name`) |
| GET/POST | `/closures` | Список и создание муфт (`name`, `lat`, `lng`) |
| PATCH/DELETE | `/closures/<id>` | Изменение и удаление муфты |
| POST | `/export` | Экспорт KMZ (`ids`, `group_by_branch`) |
| POST | `/export_tree` | Экспорт дерева ZIP (`only_visible`) |
| GET/POST/DELETE | `/folders` | Список, создание, удаление папок |
| POST | `/folders/rename`, `/folders/move` | Переименование и перенос папки одним запросом |
| GET/POST | `/state/export`, `/state/import` | Выгрузка и загрузка `state.json` |
| POST | `/gpon/geo`, `/gpon/onus` | Сохранение геобазы и списка ONU |
| POST | `/gpon/geo/point` | Точечная правка координаты (`addr`, `lat`, `lng`) |
| GET/POST/DELETE | `/gpon/state` | GPON-состояние целиком |
| GET/POST | `/gpon/state/export`, `/gpon/state/import` | Выгрузка и загрузка GPON-состояния |
| GET | `/static/*` | Локальные библиотеки и `app.js` |

Все изменяющие запросы принимают только `application/json` (загрузки — `multipart/form-data`)
и отклоняются, если пришли с чужого сайта (`Sec-Fetch-Site` / `Origin`).

## Горячие клавиши

| Режим | Клавиши |
|---|---|
| Рисование | клик — начало отрезка, клик — конец, правый клик / `Ctrl+Z` — убрать отрезок, `Enter` — сохранить, `Esc` — завершить отрезок/выйти |
| Правка геометрии | перетаскивание — сдвинуть вершину, клик по вершине — выбрать/соединить, **Shift+клик** — совместить две вершины в одну, клик по линии — вставить точку, правый клик — удалить вершину, `Ctrl+Z` — шаг назад, `Enter` — сохранить, `Esc` — сбросить отрезок/выйти |
| Вне режимов | `Ctrl+Z` — откатить последнее сохранение геометрии |

## Сборка `.exe`

```powershell
.venv\Scripts\python.exe -m PyInstaller app.spec --clean --noconfirm
```

Результат — `dist\app.exe` (templates и static упакованы внутрь). Скопируйте его в папку с `data\`
и запустите. После правок `static/app.js` или `templates/index.html` пересборка обязательна.

## Известные ограничения

- Один экземпляр на порту 5000; авторизации нет — сервис слушает только `127.0.0.1`.
- Snap к вершинам/сегментам включается кнопкой; привязки «по дорогам» нет (нужен внешний сервис маршрутизации).
- Undo хранит до 20 сохранений геометрии в пределах сессии; после перезагрузки страницы история пуста.
- Дерево маршрутов сворачивается при перезагрузке (раскрытые папки помнятся только в сессии).
- Импорт Excel/CSV выполняется в браузере: очень большие файлы (сотни тысяч строк) замедлят вкладку.
- `uploads/` не чистится автоматически полностью — копии загруженных файлов остаются на диске.
