# KMZ Routes Viewer — просмотрщик маршрутов KMZ/KML с деревом и картой

Одностраничное веб-приложение для загрузки, визуализации и редактирования маршрутов в формате KMZ/KML. Работает в браузере, есть серверная часть на Flask для сохранения изменений.

---

## Основные возможности

- **Загрузка файлов KMZ/KML** — по одному, пачкой или папкой целиком с вложенной структурой.
- **Drag & drop** — перетаскивание файлов и папок прямо в окно браузера, включая вложенные подпапки любой глубины.
- **Дерево маршрутов** — иерархия повторяет структуру папок на диске, каждая папка раскрывается.
- **Фильтр ветвей** — трёхуровневая группировка (группа → подгруппа → под-подгруппа) с чекбоксами и счётчиками.
- **Переименование** — отдельного маршрута, ветви целиком, папки.
- **Массовая замена** подстроки в именах ветвей.
- **Объединение маршрутов** в новую ветвь.
- **Изоляция ветви** — клик по линии на карте скрывает всё остальное и зумится на выбранную ветвь.
- **Экспорт KMZ** — всех видимых маршрутов с опциональной группировкой по ветвям.
- **Поиск** — по имени маршрута, имени файла, ветке и папке.
- **5 подложек** — OSM Hot, OSM DE, Esri Улицы, Esri Спутник, OpenTopoMap.
- **Тёмная и светлая тема** — переключается кнопкой, состояние сохраняется в `localStorage`.

## Установка и запуск

### 1. Скачать Python 3.10+

С сайта https://www.python.org/downloads/windows/ — **Windows installer (64-bit)**, при установке отметить ✅ **Add python.exe to PATH**.

Проверка:
```bash
python --version
```
Должно быть `Python 3.10.x`–`3.12.x` (не 3.14 — там проблемы с pip).

### 2. Установить зависимости

```bash
cd путь_к_проекту
pip install flask simplekml
```

### 3. Запустить сервер

```bash
python app.py
```

Дождаться строки:
```
 * Running on http://127.0.0.1:5000
```

Терминал **не закрывать** — пока он работает, сервер жив.

### 4. Открыть в браузере

**Вручную набрать в адресной строке:**
```
http://127.0.0.1:5000
```

⚠️ **Не открывать `index.html` двойным кликом!** Если открыть как файл (`file:///...`), браузер заблокирует `fetch()` и появится ошибка `Failed to fetch`. Нужно именно через Flask-адрес.

## Как пользоваться

### Загрузка

Три способа:

1. **📂 Загрузить KMZ** — выбрать несколько файлов через диалог.
2. **📁 Загрузить папку** — выбрать папку со всеми вложенными подпапками (браузер сохранит структуру).
3. **Перетащить** файлы или папки прямо в окно — появятся подсказка и рамка. Поддерживается вложенность любой глубины.

После загрузки структура папок на диске превращается в дерево в сайдбаре.

### Работа с маршрутом

На каждой строке маршрута (при наведении) появляются кнопки:
- **✏️** — переименовать маршрут.
- **◻/☑** — отметить для объединения.
- **✕** — удалить.
- **Чекбокс** — показать/скрыть маршрут на карте.

### Работа с ветвью

В фильтре ветвей слева у каждой ветви (при наведении):
- **✏️** — переименовать ветвь целиком (все её маршруты обновятся).
- **👁** — скрыть/показать всю ветвь.
- Двойной клик по имени — тоже открывает переименование.

Сверху — кнопка **🔄 Замена** для массовой замены подстроки во всех именах ветвей.

### Изоляция ветви на карте

- **Клик по любой линии** → все остальные маршруты скрываются, остаётся только кликнутая ветвь.
- **Повторный клик** по той же линии → снять изоляцию.
- **Клик по пустому месту карты** → снять изоляцию.
- Кнопка **✕** в бейдже изоляции в шапке → снять изоляцию.

Если у маршрута нет ветви (`branch = null`) — изолируется только он сам.

### Объединение маршрутов в ветвь

1. Отметить 2+ маршрута кнопкой **◻** → превращается в **☑**.
2. Ввести название новой ветви в поле «Название новой ветви».
3. Нажать **🚂 Объединить выбранные**.

Точки склеятся в один маршрут, который получит указанное имя ветви.

### Экспорт

- **💾 Скачать KMZ** — все видимые маршруты сохраняются в один `.kmz`.
- Опция **Группировать по ветвям** — разложить по папкам KML внутри KMZ.

## Формат входа

### KMZ (KMZ = ZIP с KML)

Внутри — файл `.kml` с `<Placemark>` элементами, содержащими `<LineString>`.

Примерная структура:
```xml
<Placemark>
  <name>Голова 4 Ветка 9</name>
  <LineString>
    <coordinates>
      38.125,45.255,0
      38.126,45.256,0
      ...
    </coordinates>
  </LineString>
</Placemark>
```

Координаты — `долгота,широта,высота`. Извлекаются первая и вторая компоненты.

Если в файле **несколько** `<LineString>`, каждая становится отдельным маршрутом с именем файла в качестве префикса.

### KML

Обычный XML, парсится тем же кодом.

## Сервер API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Главная страница (index.html) |
| POST | `/upload` | Загрузка файлов. Поля: `files[]` (сами файлы), `paths[]` (относительные пути) |
| GET | `/routes` | Список всех маршрутов с точками |
| PATCH | `/route/<id>` | Обновление маршрута. Поля: `name`, `branch`, `folder`, `visible` |
| DELETE | `/route/<id>` | Удаление маршрута |
| POST | `/merge` | Объединение нескольких в один. Поля: `ids[]`, `name` |
| POST | `/export` | Экспорт KMZ. Поля: `ids[]`, `group_by_branch` |

Данные маршрутов хранятся **в памяти** сервера (`ROUTES` dict). При перезапуске сервера — теряются. Файлы сохраняются в `uploads/`.

---

## Правила группировки ветвей в фильтре

**Уровень 1 (группа):**
- `slav*` — все, начинающиеся на `slav` (регистронезависимо)
- `bdcom-*` — все, начинающиеся на `bdcom`
- `— Прочие` — всё остальное, включая начинающиеся с `-`
- `— Без ветви` — маршруты без ветви

**Уровень 2 (подгруппа):** всё до первого `/`  
`bdcom-sla2/GPON0/1` → `bdcom-sla2`

**Уровень 3 (под-подгруппа):** всё до последнего `/`  
`bdcom-sla2/GPON0/1` → `bdcom-sla2/GPON0`

**Ветки:** полное имя маршрута  
`bdcom-sla2/GPON0/1`

Если у маршрута только один `/` (например `SLAV_PON/GPON0/5`) — третьего уровня нет, ветка попадает сразу во второй уровень.

## Ключевые функции в `app.py`

### `_parse_kml_bytes(data)`

Разбирает байты KML и возвращает список `(name, [(lat, lon), ...])` для каждой найденной `<LineString>`.

### `parse_route_file(path, ext)`

Читает KMZ (распаковывает через `zipfile`) или KML (напрямую) и передаёт содержимое в `_parse_kml_bytes`.

### `/upload`

Сохраняет файлы в `uploads/`, извлекает `folder` из относительного пути (`paths[i]`), создаёт записи в `ROUTES`. Первый сегмент относительного пути (имя выбранной папки) отрезается.

### `/export`

Собирает KMZ через `simplekml.Kml()`. При `group_by_branch=true` создаёт подпапки KML по значению `branch` каждого маршрута.

## Ключевые функции во frontend

### Работа с деревом

- `buildFolderTree()` — строит иерархию по `folder` из каждого маршрута.
- `renderFolderNode()` — рекурсивно рисует папки.
- `buildRouteLi(r)` — одна строка маршрута в дереве.

### Фильтр ветвей

- `getBranchGroup(branch)` — определяет большую группу.
- `getBranchSubgroup(branch)` — определяет подгруппу (первый сегмент).
- `getBranchSubsub(branch)` — определяет под-подгруппу (до последнего `/`).
- `renderBranchFilter()` — рисует полное дерево фильтра.

### Изоляция

- `isolateByRoute(r)` — вызывается по клику на линию. Устанавливает `State.isolation = {type: 'branch'|'route', key}` и скрывает все остальные слои.
- `clearIsolation()` — снимает изоляцию, возвращает все слои.
- Клик по карте через `map.on('click', ...)` тоже вызывает `clearIsolation`.

### Поиск

- `applySearch(q)` — фильтрует дерево по подстроке и подсвечивает маршруты на карте через `searchHighlightLayer`.

## Оптимизации

- **`preferCanvas: true`** — отрисовка линий в canvas вместо SVG.
- **Прореживание точек** через `simplify()` — только точки, отстоящие на ~3 м.
- **Кэш цветов** — `stringToColor(str)` даёт детерминированный цвет по имени.
- **Debounce** поиска (180 мс) и фильтра (120 мс).
- **Делегированные обработчики** событий.
- **Один проход** при `applyFilters()` — не пересобирает слои, а включает/выключает готовые.

## Известные проблемы и решения

### Ошибка `Failed to fetch`

**Причина:** HTML открыт как файл (`file:///...`), а не через Flask.

**Решение:** открыть `http://127.0.0.1:5000` (адрес из строки запуска Flask).

### `Invalid Python SDK` / `AttributeError: module 'typing' has no attribute 'no_type_check_decorator'`

**Причина:** в системе остался «мнимый» Python из Microsoft Store или установлен Python 3.14 с несовместимым pip.

**Решение:**
1. Отключить псевдонимы Microsoft Store: **Параметры → Приложения → Дополнительные параметры → Псевдонимы выполнения приложений → выключить `python.exe` и `python3.exe`**.
2. Установить Python 3.12 с https://www.python.org/downloads/windows/ (галочка **Add to PATH**).
3. Пересоздать venv: удалить папку `.venv`, выполнить `python -m venv .venv`, активировать, `pip install flask simplekml`.

### API KEY REQUIRED на тайлах карты

**Причина:** `basemaps.cartocdn.com` теперь требует ключ.

**Решение:** используется `tile.openstreetmap.fr/hot` — без ключа, быстрый, покрывает РФ. Альтернативы в переключателе справа сверху.

### 0 ONU на карте в GPON-проекте

**Причина:** адреса в `geo.xlsx` и `vgroups.csv` не совпадают (обычно разные регионы).

**Решение:** проверить районы командой в консоли:
```javascript
[...new Set([...State.geo.values()].map(v => {
  const m = String(v.address).match(/р-н\s+([^,]+)/i);
  return m ? m[1].trim() : '(без района)';
}))]
```
Если районы разные — нужен Excel именно с координатами соответствующего региона.
